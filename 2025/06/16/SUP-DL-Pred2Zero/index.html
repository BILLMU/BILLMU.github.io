若要让某个随机变量的期望等于标准正态分布的期望

发表于2025-06-16|更新于2025-06-16|深度学习补充知识
|浏览量:

若要让某个随机变量的期望等于标准正态分布的期望（即 $0$），并通过常数作为参数来实现这一目标，可通过以下通用方法和示例进行操作。核心思路是：利用常数调整随机变量的位置，使其均值（期望）平移至 $0$。

即通过常数 $c = -\mu$ 的平移，使新变量 $X$ 的期望为 $0$。

二、具体分布示例

以下通过不同类型的随机变量（正态分布、均匀分布、离散分布）演示如何通过常数参数使期望为 $0$。

1. 正态分布情形

原始变量：设 $Y \sim N(\mu, \sigma^2)$，期望 $E(Y) = \mu$，方差 $ \text{Var}(Y) = \sigma^2$。
构造新变量：取常数 $c = -\mu$，定义 $X = Y + c = Y - \mu$，则：

期望验证：$E(X) = \mu - \mu = 0$。
进一步标准化：若希望 $X$ 不仅期望为 $0$，还满足标准正态分布（方差为 $1$），可再引入常数 $d = \frac{1}{\sigma}$，定义 $Z = d \cdot X = \frac{Y - \mu}{\sigma}$，则：

示例：

  • 若 $Y \sim N(3, 4)$（$\mu = 3$，$\sigma = 2$），取 $c = -3$，则 $X = Y - 3 \sim N(0, 4)$，期望为 $0$；
  • 再取 $d = \frac{1}{2}$，则 $Z = \frac{X}{2} = \frac{Y - 3}{2} \sim N(0, 1)$，同时满足期望为 $0$ 且方差为 $1$。

2. 均匀分布情形

原始变量：设 $Y \sim U(a, b)$，期望 $E(Y) = \frac{a + b}{2}$，方差 $ \text{Var}(Y) = \frac{(b - a)^2}{12}$。
构造新变量：取常数 $c = -\frac{a + b}{2}$，定义 $X = Y + c = Y - \frac{a + b}{2}$，则：

期望验证：$E(X) = \frac{a + b}{2} - \frac{a + b}{2} = 0$。
示例：

  • 若 $Y \sim U(1, 5)$（$E(Y) = 3$），取 $c = -3$，则 $X = Y - 3 \sim U(-2, 2)$，期望为 $0$。

3. 离散型分布情形

原始变量：设离散随机变量 $Y$ 取值为 ${y_1, y_2, \dots, y_n}$，概率为 ${p_1, p_2, \dots, p_n}$，期望 $E(Y) = \sum y_i p_i = \mu$。
构造新变量：取常数 $c = -\mu$，定义 $X = Y + c = Y - \mu$，则：

示例：

  • 若 $Y$ 表示掷一枚公平骰子的点数（取值 $1-6$，概率均为 $\frac{1}{6}$），则 $E(Y) = 3.5$；
  • 取 $c = -3.5$，定义 $X = Y - 3.5$，则 $X$ 的期望为 $0$，取值为 ${-2.5, -1.5, -0.5, 0.5, 1.5, 2.5}$，概率均为 $\frac{1}{6}$。

三、关键总结

  1. 常数的作用：常数 $c = -\mu$ 的本质是将原始变量 $Y$ 的分布沿数轴平移，使其中心（期望）移至 $0$，该过程不改变分布的形状（如正态性、均匀性等），仅改变位置。
  2. 与标准正态分布的关联：若原始变量 $Y$ 是正态分布，通过 $c = -\mu$ 和 $d = \frac{1}{\sigma}$ 的双重调整（先平移后缩放），可使其成为标准正态分布 $N(0, 1)$；对于非正态变量，仅能通过平移使期望为 $0$，但分布形态不变。
  3. 适用场景：
    • 数据标准化：如将考试成绩平移为“以0为中心”的分数（实际中更常用 $Z$ 变换同时标准化期望和方差）；
    • 理论模型构建：在统计学中，有时需构造零均值变量以简化模型假设（如线性回归中的残差期望为0）。
