连乘转连加

发表于2025-06-16|更新于2025-06-16|机器学习补充知识数学
|浏览量:

在原文档中，逻辑回归部分涉及多处连乘公式，在对数运算等场景下，连乘可以转换为连加。这是基于对数的运算法则：$\log(ab)=\log a+\log b$（$a,b>0$），推广到多个数相乘的情况，即$\log(\prod{i = 1}^{n}a{i})=\sum{i = 1}^{n}\log a{i}$。以逻辑回归的似然函数为例进行转换说明。

  1. 原似然函数（连乘形式）：对于$n$个样本，逻辑回归的似然函数为$L(β)=\prod{i = 1}^{n}P(y_i|x_i;β)=\prod{i = 1}^{n}P(y_i = 1|x_i;β)^{y_i}(1 - P(y_i = 1|x_i;β))^{1 - y_i}$ 。这里是多个样本的概率乘积形式，在实际优化求解过程中，直接对连乘形式进行计算和求导等操作较为复杂。
  2. 转换为连加形式：对似然函数取对数，得到对数似然函数$\log L(β)=\sum_{i = 1}^{n}(y_i\log P(y_i = 1|x_i;β)+(1 - y_i)\log(1 - P(y_i = 1|x_i;β)))$ 。通过对数运算，将连乘转换为连加，简化了后续的计算过程。在求解损失函数最小值时，对连加形式的对数似然函数进行求导和优化会更加方便，因为加法的求导规则相对简单，如$(u + v)^\prime=u^\prime + v^\prime$，相比连乘的求导（如$(uv)^\prime = u^\prime v + uv^\prime$，推广到多个数连乘的求导更为复杂），计算复杂度降低，更易于实现模型的训练和参数优化。
