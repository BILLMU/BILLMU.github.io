5.1 逻辑回归简介

5.1.1 什么是逻辑回归

逻辑回归（Logistic Regression）是用于解决分类问题的统计方法，常用于二分类任务。尽管名称中有“回归”，但它主要用于分类任务。
它通过sigmoid函数将线性回归输出映射到[0,1]区间，以此表示某个类别的概率。

sigmoid函数为$f(x)=\frac{1}{1 + e^{-x}}$ ，导数是$f’(x)=f(x)(1 - f(x))$。

即当x趋近于正无穷时趋近于1，趋近于负无穷时趋近于0 种群在有限生存环境中的繁衍情况

5.1.2 逻辑回归应用场景

逻辑回归在多个领域有广泛应用，如信用评分（预测客户违约可能性）、欺诈检测（判断交易是否欺诈）、垃圾邮件检测（识别邮件是否为垃圾邮件）、广告点击预测（预测用户是否点击广告）、图像分类（对图像进行类别划分）、情感分析（判断文本情感倾向）、产品质量分类（预测产品是否合格）、医学诊断（判断患者是否患病）以及蛋白质功能预测（基于蛋白质特征预测功能类别）等。

5.1.3 逻辑回归损失函数

逻辑回归常用对数损失（Log Loss），也叫二元交叉熵损失（Binary Cross - Entropy Loss），源于最大似然估计（MLE），用于衡量模型输出概率分布与真实标签的差距。

$P(Y|X;β)$ 表示给定输入特征 $x$ 和模型参数 $β$ 时，因变量 $y$ 发生的概率，整合后为

似然函数 $L(β)$ 表示已知$y$结果时，模型参数为 $β$ 的概率，

对于一个样本$L(\beta)=P(y\mid x;\beta)=P(y = 1\mid x;\beta)^y(1 - P(y = 1\mid x;\beta))^{1 - y}$

$n$个样本的似然函数为$L(β)=\prod{i = 1}^{n}P(y_i|x_i;β)=\prod{i = 1}^{n}P(y_i = 1|x_i;β)^{y_i}(1 - P(y_i = 1|x_i;β))^{1 - y_i}$ ，

取对数似然为$\log L(β)=\sum_{i = 1}^{n}(y_i\log P(y_i = 1|x_i;β)+(1 - y_i)\log(1 - P(y_i = 1|x_i;β)))$ 。

5.2 多分类任务（了解）

逻辑回归通过一对多（One - vs - Rest，OvR）和Softmax回归（Multinomial Logistic Regression，多项逻辑回归）方法可扩展到多分类任务。

5.2.1 一对多（OVR）

  1. 实现方式：若存在$C$个类别，需训练$C$个二分类逻辑回归分类器。每个分类器将一个类别设为正例，其余类别设为反例。预测时，计算$C$个分类器的输出概率，选择概率最高的类别作为预测结果。对于类别$c$ ，

    $P(y = c|x;β)=\frac{1}{1 + e^{-(β^Tx)}}$ ，

    $Loss = -\frac{1}{n}\sum_{i = 1}^{n}(y_i\log P(y_i = c|x_i;β)+(1 - y_i)\log(1 - P(y_i = c|x_i;β)))$ 。

  2. 优缺点：优点是实现简单，适用于类别数量较少的场景；缺点是当类别数量较多时，训练时间较长，因为每个类别都需训练一个分类器。
