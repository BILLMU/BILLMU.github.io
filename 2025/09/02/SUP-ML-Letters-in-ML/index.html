机器学习中的字母

总结表

希腊字母 符号 常见含义 应用场景
Alpha α 学习率、正则化参数 优化算法、正则化
Beta β 线性回归系数、Beta 分布参数 回归模型、贝叶斯统计
Gamma γ 核函数参数、折扣因子 SVM、强化学习
Delta δ 误差项、梯度更新量 模型训练、优化
Epsilon ε 随机噪声、探索率 数据模型、强化学习
Theta θ 模型参数 线性回归、逻辑回归
Lambda λ 正则化强度、拉格朗日乘子 正则化系数、约束优化
Mu μ 均值、权重初始化 统计、神经网络
Pi π 策略函数、混合比例 强化学习、混合模型
Sigma σ 标准差、Sigmoid 函数 统计、神经网络
Omega ω 模型参数、正则化惩罚 线性模型、正则化
Nabla ∇ 梯度算子 优化算法
Xi $\xi$ 松弛变量 线性支持向量机-软间隔

记忆技巧

  • 参数相关：θ、ω、β 通常表示模型参数
  • 优化相关：α（学习率）、∇（梯度）、γ（衰减因子）、λ（正则化系数）
  • 统计相关：μ（均值）、σ（标准差）
  • 分布相关：Beta (α, β)、π（混合比例）

1. α (Alpha)

  • 学习率：在梯度下降等优化算法中，控制参数更新的步长。 例如：$θ = θ - α ∇J(θ)$
  • 正则化参数：如在 Lasso 回归和 Ridge 回归中，控制惩罚项的强度。 例如：$J(θ) = \text{MSE} + α |θ|_1$（Lasso）
  • Alpha 融合：在集成学习中，加权多个模型的预测结果。

2. β (Beta)

  • 线性回归系数：表示特征对目标变量的影响程度。 例如：$y = β_0 + β_1x_1 + β_2x_2$
  • 逻辑回归参数：控制对数几率模型的形状。 例如：$\text{logit}(P) = β_0 + β_1x$
  • Beta 分布：贝叶斯统计中用于表示概率的概率分布。 例如：$P \sim \text{Beta}(α, β)$
  • Fβ 分数：评估指标中平衡精确率和召回率的权重参数。

3. γ (Gamma)

  • 核函数参数：在 SVM 和核方法中，控制核函数的宽度。 例如：$γ = \frac{1}{2σ^2}$（RBF 核）
  • 学习率衰减因子：随着训练迭代逐渐减小学习率。 例如：$α_t = α_0 \cdot γ^t$
  • 折扣因子：强化学习中，对未来奖励的折现率。 例如：$Gt = \sum{k=0}^∞ γ^k R_{t+k+1}$

4. δ (Delta)

  • 误差项：表示预测值与真实值之间的差异。 例如：$δ = y - \hat{y}$
  • 梯度更新量：参数的变化量。 例如：$Δθ = -α ∇J(θ)$
  • 克罗内克 δ：在张量运算中表示单位矩阵。 例如：$δ_{ij} = \begin{cases} 1 & \text{if } i=j \ 0 & \text{otherwise} \end{cases}$

5. ε (Epsilon)

  • 随机噪声：在数据生成模型中，表示随机扰动。 例如：$y = f(x) + ε$，其中$ε \sim \mathcal{N}(0, σ^2)$
  • 正则化参数：如在弹性网络中控制 L1 和 L2 惩罚的平衡。
  • 探索率：强化学习中 ε- 贪心策略的探索概率。
  • 支持向量机的不敏感损失参数：定义不影响损失的误差范围。

6. θ (Theta)

  • 模型参数：在线性回归、逻辑回归等模型中表示待学习的权重。 例如：$h_θ(x) = θ_0 + θ_1x_1 + \dots + θ_nx_n$
  • 角度：在某些几何解释或旋转操作中使用。

7. λ (Lambda)

  • 正则化强度：控制 L1/L2 正则化的惩罚力度。 例如：$J(θ) = \text{MSE} + λ |θ|_2^2$（Ridge 回归）
  • 拉格朗日乘子：约束优化问题中引入的参数。
  • 指数分布参数：表示事件发生的速率。

8. μ (Mu)

  • 均值：表示数据分布的中心位置。 例如：$\mathcal{N}(μ, σ^2)$ 表示均值为 μ 的正态分布
  • 权重初始化参数：在神经网络中，控制初始权重的分布。
  • 迁移学习中的源域权重：平衡源域和目标域的影响。

9. π (Pi)

  • 策略函数：在强化学习中，表示状态到动作的映射。 例如：$π(a|s)$ 表示在状态 s 下采取动作 a 的概率
  • 比例：如在混合模型中，表示各成分的权重。 例如：高斯混合模型中$π_k$表示第 k 个高斯成分的权重
  • 数学常数：约等于 3.14159，在某些公式中出现。

10. σ (Sigma)

  • 标准差：表示数据分布的离散程度。 例如：$\mathcal{N}(μ, σ^2)$ 中的 σ
  • Sigmoid 函数：神经网络中常用的激活函数。 例如：$σ(z) = \frac{1}{1 + e^{-z}}$
  • 求和符号：数学中表示累加运算（大写 Σ）。

11. ω (Omega)

  • 模型参数：与 θ 类似，表示神经网络或线性模型中的权重。 例如：$y = ω_0 + ω_1x_1 + \dots + ω_nx_n$
  • 正则化惩罚项：如在 L2 正则化中，$Ω(θ) = \frac{1}{2} \sum_{i=1}^n θ_i^2$

12. ∇ (Nabla)

  • 梯度算子：表示函数的导数或偏导数。 例如：$∇J(θ)$ 表示损失函数 J 关于参数 θ 的梯度
